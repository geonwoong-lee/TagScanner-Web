# 브랜드 기준 벡터 다시 만드는 방법

`brand_vectors.js` 는 택 사진으로 브랜드를 추정할 때 쓰는 기준값이다.
브랜드를 늘리거나 사진을 더 모았을 때 아래 순서로 다시 만든다.

1. 로컬 서버를 띄우고 앱을 연다 (`python -m http.server 8765`)
2. 브라우저 콘솔에서 평가셋 전체의 임베딩을 계산한다

```js
const gt = await (await fetch('/eval/ground_truth.json')).json();
const out = {};
for (const row of gt) {
  const blob = await (await fetch('/eval/images/' + row.id + '.jpg')).blob();
  const dataUrl = await new Promise(r => { const f = new FileReader(); f.onload = () => r(f.result); f.readAsDataURL(blob); });
  out[row.id] = { brand: row.brand, v: await window.CLIP.computeImageEmbedding(dataUrl) };
}
```

3. 브랜드별로 평균을 내고 길이를 1로 맞춘다
4. 정확도는 자기 자신을 뺀 상태로 잰다 (leave-one-out). 지금 값은 127/135 (94.1%)
5. 작게 담기 위해 정수로 줄여 base64로 적고 scale을 함께 저장한다

## 주의

기준에 없는 브랜드를 "모른다"고 답할 방법이 없다.
맞힌 경우 유사도 중앙값 0.92, 틀린 경우도 0.89까지 올라와 구간이 겹친다.
그래서 자동으로 채우지 않고 사용자가 고르게 되어 있다.
