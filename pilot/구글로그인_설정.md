# 구글 로그인 켜기 (직접 하셔야 하는 설정)

앱 쪽 코드는 다 들어가 있다. 아래 두 군데만 설정하면 동작한다. 10분 걸린다.

## 1. 구글 클라우드에서 OAuth 클라이언트 만들기

1. https://console.cloud.google.com/apis/credentials 접속
   (Vision API 쓰던 그 프로젝트 그대로 쓰면 된다)
2. 처음이면 **OAuth 동의 화면**을 먼저 만든다
   - User Type: **외부**
   - 앱 이름: `TagScanner`
   - 사용자 지원 이메일, 개발자 연락처: 본인 이메일
   - 범위는 기본값 그대로 두고 저장
   - 테스트 사용자에 참가자 이메일을 넣거나, 게시 상태를 **프로덕션**으로 바꾼다
     (테스트 상태로 두면 등록한 사람만 로그인된다. 참가자가 늘면 프로덕션이 편하다)
3. **사용자 인증 정보 만들기 > OAuth 클라이언트 ID**
   - 애플리케이션 유형: **웹 애플리케이션**
   - 이름: `TagScanner Web`
   - **승인된 리디렉션 URI** 에 아래 주소를 넣는다

```
https://vvuxqnjeawujkbudhxhy.supabase.co/auth/v1/callback
```

   주의: 우리 사이트 주소가 아니라 Supabase 주소다. 구글은 Supabase로 보내고,
   Supabase가 다시 우리 사이트로 돌려보낸다.

4. 만들면 **클라이언트 ID**와 **클라이언트 보안 비밀**이 나온다. 둘 다 복사

## 2. Supabase에 넣기

1. Supabase 대시보드 > **Authentication** > **Sign In / Providers**
2. 목록에서 **Google** 을 찾아 켠다
3. Client ID, Client Secret 붙여넣고 저장

## 3. 돌아올 주소 등록

1. Authentication > **URL Configuration**
2. **Site URL**: `https://geonwoong-lee.github.io/TagScanner-Web/`
3. **Redirect URLs** 에 같은 주소를 추가

이게 없으면 구글 인증은 되는데 앱으로 돌아오지 못한다.

## 확인

앱 로그인 화면에서 "구글 계정으로 계속하기" 를 누르면
구글 화면으로 갔다가 다시 돌아온다. 처음 들어온 계정은
참가자 번호와 동의를 받는 화면이 먼저 뜬다.

## 참고

- 구글로 들어와도 기존 계정과 똑같이 동작한다. 자기 데이터만 보이고 기기 간 동기화도 된다
- 같은 이메일로 이메일 가입을 이미 했다면 Supabase가 같은 계정으로 묶는다
- 동의를 받기 전에는 앱을 쓸 수 없게 막아 두었다. 동의 없이 수집하면 안 되기 때문이다
