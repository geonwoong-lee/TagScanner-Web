# TagScanner 파일럿 테스트 참가 안내

서울과학기술대학교 캡스톤디자인 과제로 만든 TagScanner를 2주간 써보고 의견을 주실 분을 찾습니다.

## 어떤 앱인가

옷 가게에서 마음에 드는 옷을 발견했을 때, 가격표나 품질표시 태그를 찍으면 브랜드, 가격, 사이즈, 소재, 세탁법을 읽어서 자동으로 정리해 줍니다. 나중에 여러 벌을 나란히 놓고 비교할 수 있습니다.

메모장에 적거나 사진만 찍어두면 나중에 뭐가 뭔지 헷갈리는데, 그걸 해결하려고 만들었습니다.

## 기간과 부탁드리는 일

**기간**: 2주

**부탁드리는 일**
- 옷 가게에 가면 마음에 드는 옷의 태그를 찍어서 저장해 주세요
- 사고 말고에 상관없이, 살까 고민한 옷이면 다 좋습니다
- 옷 사진이나 입어본 사진도 같이 넣어주시면 좋습니다
- 두 벌 이상 모이면 비교 화면을 한 번 써봐 주세요
- 끝나고 간단한 설문에 답해 주세요 (10분 정도)

많이 써주실수록 좋지만, 억지로 만들어내실 필요는 없습니다. 평소 쇼핑하시는 대로 쓰시면 됩니다.

## 시작하는 방법

### 1. 홈 화면에 추가하기

휴대폰 브라우저에서 아래 주소를 엽니다.

https://geonwoong-lee.github.io/TagScanner-Web/

**아이폰(사파리)**: 아래쪽 공유 버튼 > 홈 화면에 추가
**안드로이드(크롬)**: 오른쪽 위 점 세 개 > 홈 화면에 추가

아이콘이 생기고, 그걸로 열면 주소창 없이 앱처럼 뜹니다. 브라우저에서 바로 써도 되지만 홈 화면에 두시는 쪽을 권합니다.

### 2. 회원가입

- 이메일과 비밀번호(6자 이상)를 넣습니다. 확인 메일은 가지 않습니다
- 참가자 번호는 따로 알려드립니다 (P01 형식)
- 수집 내용을 읽고 동의에 체크하신 뒤 가입합니다

로그인해두면 휴대폰과 컴퓨터 어디서 열어도 저장한 내용이 그대로 보입니다.

### 3. 사용하기

- 가운데 큰 버튼으로 태그를 찍습니다. 태그가 가이드 선 안에 들어오게 맞춰주세요
- 2초 안에 인식이 끝나고 브랜드, 가격, 사이즈가 자동으로 채워집니다
- 틀린 곳이 있으면 직접 고쳐주세요. **이게 저희한테 제일 중요한 정보입니다**
- 옷 사진 추가, 착용샷 추가 버튼으로 사진을 더 넣을 수 있습니다
- 하트를 누르면 비교 목록에 들어갑니다
- 찜 목록에서 한눈에 비교하기를 누르면 여러 벌을 나란히 볼 수 있습니다

## 수집하는 내용

| 항목 | 내용 |
|---|---|
| 상품 정보 | 브랜드, 상품명, 가격, 사이즈, 소재, 세탁법, 매장, 메모 |
| 사진 | 태그 사진, 옷 사진, 착용 사진 |
| 사용 기록 | 저장, 비교, 찜을 누른 시각과 횟수 |

**목적**: 캡스톤디자인 과제의 인식 정확도 측정과 사용성 분석
**보관 기간**: 과제가 끝나는 시점까지, 이후 삭제
**공개 범위**: 과제 팀과 지도교수만 봅니다. 외부에 공개하지 않고, 발표 자료에 쓸 때는 개인을 알아볼 수 없게 처리합니다

참가자 본인 데이터는 본인만 볼 수 있게 서버에서 막아두었습니다. 다른 참가자의 옷이나 사진은 보이지 않습니다.

## 그만두고 싶을 때

언제든 그만두셔도 됩니다. 이유를 말씀하실 필요 없습니다. 연락 주시면 계정과 그동안 저장된 내용을 전부 지워드립니다. 중간에 그만두셔도 불이익은 없습니다.

착용샷처럼 넣기 부담스러운 사진은 안 넣으셔도 됩니다. 앱 쓰는 데 아무 지장 없습니다.

## 이런 게 있으면 알려주세요

버그 제보가 아니라도 좋습니다. 쓰면서 불편했던 순간이 저희한테는 제일 쓸모있는 정보입니다.

- 인식이 엉뚱하게 된 태그 (화면 캡처해 주시면 좋습니다)
- 버튼을 어디 눌러야 할지 몰라 헤맨 부분
- 있으면 좋겠다 싶은 기능
- 앱이 멈추거나 화면이 깨진 경우

연락처: (여기에 카카오톡 아이디나 이메일을 적으세요)

## 자주 묻는 질문

**데이터가 얼마나 드나요**
사진 한 장당 1MB 이하입니다. 하루에 몇 장 찍는 정도면 거의 영향 없습니다.

**인터넷이 안 되는 곳에서도 되나요**
저장은 됩니다. 다만 태그 자동 인식은 인터넷이 필요합니다. 인터넷이 다시 연결되면 저장한 내용이 서버로 올라갑니다.

**태그 인식이 자꾸 틀려요**
태그 전체가 화면에 들어오게, 밝은 곳에서, 그림자가 지지 않게 찍으면 잘 됩니다. 그래도 틀리면 그냥 직접 고쳐서 저장해 주세요. 어떤 태그가 틀리는지 모으는 것도 저희 목표 중 하나입니다.

**사진을 잘못 찍었어요**
상품 상세 화면에서 사진을 눌러 삭제하거나 대표 사진을 바꿀 수 있습니다.

**앱을 지우면 데이터도 사라지나요**
아닙니다. 로그인 정보로 다시 들어오면 그대로 있습니다.
