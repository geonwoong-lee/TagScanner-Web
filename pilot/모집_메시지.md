# 모집할 때 보낼 짧은 메시지

카카오톡이나 DM으로 보낼 용도. 긴 안내문은 가입한 사람에게 따로 전달.

---

안녕하세요. 서울과기대 캡스톤디자인 과제로 옷 태그를 찍으면 브랜드랑 가격, 소재를 자동으로 정리해 주는 앱을 만들었습니다. 2주간 써보고 의견 주실 분을 찾고 있습니다.

옷 가게에서 마음에 드는 옷 발견했을 때 태그 한 번 찍어주시면 됩니다. 사고 말고는 상관없고, 살까 고민한 옷이면 다 좋습니다. 평소 쇼핑하시는 대로만 쓰시면 됩니다.

설치는 따로 없고 주소 열어서 홈 화면에 추가하면 앱처럼 씁니다. 끝나고 10분짜리 설문 하나 부탁드립니다.

저장한 옷 정보랑 사진, 앱 사용 기록을 모읍니다. 과제 분석에만 쓰고 끝나면 지웁니다. 본인 데이터는 본인만 볼 수 있게 되어 있습니다. 중간에 그만두셔도 괜찮습니다.

해주실 수 있으면 알려주세요. 참가자 번호랑 자세한 안내 보내드리겠습니다.
