# TagScanner

매장에서 마음에 든 옷의 택을 찍어 두면 브랜드, 가격, 사이즈 같은 정보를 자동으로 정리해 주는 웹앱입니다.
집에 와서 후보 상품을 한곳에서 보고 비교할 수 있게 하는 것이 목표입니다.

사이트: https://geonwoong-lee.github.io/TagScanner-Web/

## 만든 이유

오프라인 매장에서 옷을 고를 때 바로 사지 않고 사진만 찍어 두는 경우가 많습니다.
상품 사진, 택 사진, 메모가 갤러리와 메모장에 흩어지다 보니 나중에 어떤 브랜드였는지, 가격이 얼마였는지 다시 찾기 어렵고 비교도 번거롭습니다.
TagScanner는 택 사진 한 장으로 필요한 정보를 뽑아 저장하고, 저장한 상품을 정리하고 비교하는 데까지 이어지도록 만들었습니다.

## 주요 기능

- 택 촬영 또는 사진 업로드
- 택에서 브랜드, 상품명, 가격, 사이즈, 품번, 소재 자동 추출 (잘못 읽은 값은 바로 수정 가능)
- 내 상품 목록: 브랜드, 등록 기간, 가격대 필터와 정렬, 찜한 상품만 보기
- 상품 상세: 온라인 최저가 검색, 브랜드 공식몰 이동, 내 옷장에서 비슷한 옷 찾기
- 찜한 상품 2개 이상을 한 화면에서 비교
- 마이페이지: 저장 통계, 스타일 분석, OCR 설정, 데이터 내보내기(JSON)와 전체 삭제

## 시작하기

1. 사이트에 접속합니다.
2. 마이페이지의 설정에서 Google Cloud Vision API 키를 입력합니다.
   키가 없으면 브라우저 안에서 도는 Tesseract.js로 인식하는데, 한글 택에서는 정확도가 많이 떨어집니다.
3. 첫 화면에서 택을 찍거나 사진을 올리면 추출 결과가 입력 화면에 채워집니다.

API 키와 저장한 상품은 모두 사용하는 브라우저의 localStorage에만 저장됩니다. 별도 서버는 없습니다.
브라우저 데이터를 지우면 함께 사라지니 필요하면 마이페이지에서 JSON으로 내보내 두세요.

## 브랜드 인식 방식

택마다 브랜드를 표시하는 방식이 달라서 한 가지 방법으로는 부족했습니다. 아래 순서대로 확인하고, 앞 단계에서 브랜드가 정해지면 뒤 단계는 건너뜁니다.

1. 로고 인식
   Google Vision의 로고 인식 결과를 쓰되, 자체 브랜드 사전에 있는 브랜드일 때만 받아들입니다.
   Vision이 택의 FSC 인증 마크를 브랜드로 읽는 경우가 있어서 이렇게 걸렀습니다.
2. 브랜드명 텍스트
   택에서 읽은 글자를 브랜드 사전(114개 브랜드의 영문명, 한글명, 공식몰 주소)과 대조합니다.
   `UNI`와 `QLO`처럼 로고가 두 줄로 나뉘어 읽히면 이어 붙여 보고, 6자 이상 영문명은 한 글자 오타까지 맞춥니다.
3. 택 양식
   브랜드명이 아예 인쇄되지 않는 택은 브랜드마다 고유한 코드 형식으로 구분합니다.
   예를 들어 COS는 `KX 11`, H&M은 `KR 11`, ARKET은 `BP 1 10xx`, 무인양품은 바코드가 `4550`으로 시작합니다.
   이 규칙에 걸리지 않으면 택 사진에서 학습한 양식 특징으로 추정하고, 확신이 낮을 때는 자동으로 채우지 않고 후보로만 보여 줍니다.

가격은 통화 기호와 금액이 다른 줄로 읽혀도 잡고, 사이즈와 품번은 브랜드별 표기(`XL(86-88)`, `95/M`, `070(S)`, `ART.: 6045/350/400` 등)를 따로 처리합니다.
소재는 소재 용어 사전(74개 용어)을 기준으로 혼용률을 정리합니다.

## 인식 정확도

SPA 9개 브랜드(SPAO, ARKET, H&M, COS, MUJI, 무신사 스탠다드, 8seconds, ZARA, UNIQLO) 매장에서 브랜드별 15장씩, 총 135장의 택을 직접 찍어 측정했습니다.

| 항목 | 개선 전 | 개선 후 |
|---|---|---|
| 브랜드 | 51% | 100% |
| 가격 | 37% | 100% |
| 사이즈 | 62% | 98% |
| 품번 | 29% | 99% |
| 상품명 | 12% | 93% |
| 소재(혼용률) | 지원 안 함 | 24장 중 23장 |

인식 규칙을 이 135장을 보면서 만들었기 때문에 처음 보는 택에서는 수치가 더 낮을 수 있습니다. 새로 찍은 사진으로 다시 측정할 예정입니다.

택 사진을 이미지 그대로 비교하는 방식(CLIP)도 따로 실험했습니다. 가장 비슷한 택의 브랜드를 답으로 삼았을 때 135장 중 130장(96.3%)을 맞혔고, 사진을 흑백으로 바꾸고 배경을 잘라내도 같은 결과가 나왔습니다. 아직 브랜드 인식에는 쓰지 않고 있습니다.

## 로컬에서 실행하기

빌드 과정이 없는 정적 사이트입니다. 파일을 더블클릭해서 열면 일부 기능이 막히므로 간단한 로컬 서버로 여세요.

```bash
python -m http.server 8000
```

브라우저에서 http://localhost:8000 에 접속하면 됩니다.

## 폴더 구조

```
index.html        화면 구성
app.js            화면 동작, OCR 호출, 저장과 비교
parser.js         OCR 결과에서 항목을 뽑는 규칙
brands.js         브랜드 기준 데이터 (표기명, 한글명, 공식몰)
fabric_dict.js    소재 용어 사전
tag_profiles.js   택 양식 특징 (eval/build_profiles.js가 생성, 직접 수정하지 않음)
clip.js           이미지 임베딩 (비슷한 옷 찾기, 스타일 분석)
styles.css        스타일
eval/             인식률 평가 도구와 정답 라벨
```

## 인식률 평가

`eval/`에 정답 라벨과 택 135장의 Vision 응답이 들어 있어서, API 키나 사진 없이 정확도를 다시 계산할 수 있습니다.

```bash
node eval/evaluate.js parser.js v3
```

파서를 고친 뒤에는 이 명령으로 수치가 떨어지지 않았는지 확인합니다. 자세한 내용은 [eval/README.md](eval/README.md)에 있습니다.
원본 택 사진은 용량과 공개 범위 문제로 저장소에 올리지 않았습니다.

## 알려진 한계

- 비슷한 옷 찾기와 스타일 분석은 처음 쓸 때 이미지 모델(약 40MB)을 내려받느라 30초 가까이 걸립니다. 한 번 받은 뒤에는 브라우저에 저장됩니다.
- 브랜드 사전에 없는 브랜드는 자동으로 잡지 못할 수 있습니다. 이때는 후보 버튼에서 고르거나 직접 입력합니다.
- 외부 상품 검색은 상품 데이터 파일(`products_db.json`)이 아직 없어 꺼져 있습니다.
