# TagScanner

오프라인 매장에서 마음에 든 옷의 택을 찍으면 브랜드, 가격, 사이즈, 소재를 자동으로 정리하고,
저장한 후보 상품을 비교해 구매 결정을 돕는 웹앱입니다.

서울과학기술대학교 캡스톤디자인(2)

## 바로 실행하기

설치 파일이 따로 없는 웹 애플리케이션입니다. 아래 주소를 브라우저로 열면 바로 실행됩니다.

**https://geonwoong-lee.github.io/TagScanner-Web/**

1. 위 주소에 접속합니다. 휴대폰에서 여는 것을 권장합니다 (카메라로 택을 찍기 때문)
2. 로그인 화면에서 **구글 계정으로 계속하기**를 누르거나, 이메일로 회원가입합니다
3. 처음 들어오면 참가자 번호와 데이터 수집 동의를 입력합니다
4. 가운데 촬영 버튼으로 택을 찍거나, **갤러리에서 사진 고르기**로 사진을 올립니다
5. 인식된 브랜드, 가격, 사이즈를 확인하고 저장합니다

휴대폰에서는 브라우저의 **홈 화면에 추가**를 쓰면 주소창 없이 앱처럼 열립니다.

- 아이폰: 사파리 아래쪽 공유 버튼 > 홈 화면에 추가
- 안드로이드: 크롬 오른쪽 위 점 세 개 > 홈 화면에 추가

## 운영 환경

| 구분 | 내용 |
|---|---|
| 실행 환경 | 웹 브라우저 (iOS Safari, Android Chrome, PC Chrome에서 확인) |
| 화면 | HTML, CSS, JavaScript. 프레임워크와 빌드 과정 없음 |
| 배포 | GitHub Pages |
| 계정·DB·사진 저장 | Supabase (인증, PostgreSQL, Storage) |
| 글자 인식 | Google Cloud Vision API. Supabase Edge Function이 대신 호출하므로 키가 브라우저에 노출되지 않음 |
| 이미지 비교 | CLIP (`Xenova/clip-vit-base-patch32`). Transformers.js로 브라우저 안에서 실행 |
| 로그인 | 이메일 회원가입, 구글 OAuth |
| 사용 기록 | Supabase, Google Analytics 4 |

## 주요 기능

**택 인식**
- 택 사진에서 브랜드, 상품명, 가격, 사이즈, 품번, 소재, 세탁법, 카테고리를 자동으로 채웁니다
- 글자로 브랜드를 찾지 못하면 택 사진 모양을 CLIP으로 비교해 브랜드 후보를 제안합니다
- 사진이 흐리거나 어둡거나 주요 항목을 못 찾으면 다시 찍을지 묻습니다

**저장과 비교**
- 상품마다 택 사진, 옷 사진, 착용 사진을 여러 장 저장합니다
- 찜한 상품을 한 화면에 나란히 놓고 가격, 사이즈, 소재, 세탁법, 사진을 비교합니다
- 비교하면서 샀어요, 보류, 안 사기로를 고르면 나머지는 보류로 넘어갑니다
- 옷장에 비슷한 옷이 이미 있으면 알려 줍니다
- 무신사, 구글, 네이버에서 가격을 찾고, 본 가격을 적으면 매장가와의 차이를 보여 줍니다
- 카카오톡 등으로 상품 정보를 공유합니다

**마이페이지**
- 나의 소비 성향 (FR-08): 저장·찜·비교 비율, 가격 중앙값, 카테고리별 비율, 관심 브랜드 TOP3
- 먼저 살펴볼 상품 (FR-09): 저장한 상품 중 우선순위 TOP3와 근거
- 이번 달 지출, 오래 보류한 상품 다시 보기

**계정**
- 로그인하면 휴대폰과 컴퓨터 어디서 열어도 같은 내용이 보입니다
- 다른 사람의 상품과 사진은 보이지 않도록 서버에서 계정 단위로 막혀 있습니다

## FR-09 우선순위 계산

새 상품을 찾아 주는 기능이 아니라, 이미 저장한 상품 안에서 먼저 볼 순서를 정합니다.

| 항목 | 만점 |
|---|---:|
| 찜 | 25 |
| 비교 | 20 |
| 자주 저장한 카테고리 | 20 |
| 자주 저장한 브랜드 | 15 |
| 평소 가격대와 가까움 | 20 |

평가하는 상품은 기준에서 빼고 계산합니다. 샀거나 포기한 상품은 빠집니다.
점수는 구매 확률이 아니며, 가중치는 처음 정한 설계값으로 검증을 거친 값이 아닙니다.
자세한 산식과 예외 처리는 [pilot/FR08_FR09.md](pilot/FR08_FR09.md)에 있습니다.

## 로컬에서 실행하기

빌드 과정이 없습니다. 저장소를 받은 뒤 폴더에서 로컬 서버를 열면 됩니다.
파일을 더블클릭해서 열면 카메라와 저장소 기능이 막히므로 서버로 열어야 합니다.

```bash
python -m http.server 8000
```

브라우저에서 http://localhost:8000 에 접속합니다.

로컬에서도 배포판과 같은 Supabase 서버에 연결됩니다. 글자 인식은 로그인해야 동작합니다.
구글 로그인은 배포 주소로 돌아가도록 설정되어 있어 로컬에서는 이메일 로그인을 쓰는 편이 편합니다.

## 테스트

외부 패키지 없이 Node만 있으면 됩니다.

```bash
node tests/insights.test.js
```

FR-08, FR-09 계산을 확인합니다 (27개 항목).

```bash
node eval/evaluate.js parser.js v3
```

택 135장의 저장된 Vision 응답으로 인식 정확도를 다시 계산합니다. API 키나 사진이 필요 없습니다.

## 인식 정확도

SPA 9개 브랜드(SPAO, ARKET, H&M, COS, MUJI, 무신사 스탠다드, 8seconds, ZARA, UNIQLO) 매장에서
브랜드별 15장씩, 총 135장의 택을 직접 찍어 측정했습니다.

| 항목 | 개선 전 | 개선 후 |
|---|---|---|
| 브랜드 | 51% | 100% |
| 가격 | 37% | 100% |
| 사이즈 | 62% | 97.8% |
| 품번 | 29% | 98.5% |
| 상품명 | 12% | 93.3% |

인식 규칙을 이 135장을 보면서 만들었으므로 처음 보는 택에서는 수치가 더 낮을 수 있습니다.

택 사진 이미지 비교(CLIP)로 브랜드를 맞히는 방식은 자기 자신을 뺀 상태에서 135장 중 127장(94.1%)을 맞혔습니다.
처음 보는 브랜드를 거를 방법이 없어 자동으로 채우지 않고 후보로만 보여 줍니다.

## 폴더 구조

```
index.html          화면 구성
app.js              화면 동작, 촬영, 저장, 비교, 마이페이지
parser.js           인식 결과에서 항목을 뽑는 규칙
insights.js         소비 성향 분석과 우선순위 계산 (FR-08, FR-09)
cloud.js            로그인, 동기화, 사용 기록, 서버 호출
photos.js           사진 저장소 (IndexedDB)
clip.js             이미지 임베딩 (비슷한 옷, 스타일 분석, 택 모양 브랜드 추정)
brands.js           브랜드 기준 데이터
brand_vectors.js    택 모양 브랜드 추정용 기준값
fabric_dict.js      소재 용어 사전
tag_profiles.js     택 양식 특징 (eval/build_profiles.js가 생성)
config.js           공개 설정값 (Supabase 주소와 공개 키, GA 측정 ID)
styles.css          스타일
privacy.html        개인정보처리방침
redirect.html       외부 검색으로 넘어갈 때 거치는 페이지
manifest.json       홈 화면 추가 설정
tests/              계산 테스트
eval/               인식률 평가 도구와 정답 라벨
pilot/              DB 스키마, 서버 함수, 설정 안내, 분석 쿼리
```

`config.js`에는 브라우저에 공개되어도 되는 값만 있습니다.
구글 Vision 키와 OAuth 비밀값은 Supabase 서버에만 있고 이 저장소에는 없습니다.

## 서버를 새로 세울 때

같은 서버를 쓰면 필요 없습니다. 다른 Supabase 프로젝트로 옮길 때만 해당합니다.

1. [pilot/schema.sql](pilot/schema.sql)을 SQL Editor에서 실행
2. [pilot/vision-proxy.ts](pilot/vision-proxy.ts)를 Edge Function `vision`으로 배포하고 `GOOGLE_VISION_API_KEY` 등록
3. `config.js`의 주소와 공개 키를 새 프로젝트 값으로 교체
4. 구글 로그인이 필요하면 [pilot/구글로그인_설정.md](pilot/구글로그인_설정.md) 참고

## 알려진 한계

- 이미지 비교 기능은 처음 쓸 때 모델(약 40MB)을 내려받느라 30초 가까이 걸립니다. 이후에는 1초 안에 끝납니다
- 브랜드 사전에 없는 브랜드는 자동으로 잡지 못할 수 있습니다
- 온라인 가격은 자동으로 가져오지 않고 직접 적습니다. 공개된 쇼핑 검색 API가 없고, 쇼핑몰 자동 수집은 약관에 막혀 있습니다
- 우선순위 가중치는 검증되지 않은 초기값입니다
